3D Models

Diorama

This is a diorama with the main subject being the Japanese youkai, karakasa kozou. This piece features a short animation that makes use of basic rigs, as well as a special effect to give the diorama the effect of a bold, cartoonish outline around the models.

Drawing inspiration from old scroll art, the scenery was kept mainly dark and utilised muted colours in order to allow karakasa kozou and its shiny coin to stand out. The intentions behind the inclusion of each part of the diorama can be viewed using the link above.

Virtual Environment

This is a playable Unity project, with all models being made by myself. Following the brief, this project was made to represent more personal troubles in my life.

The primary intention was to be somewhat surreal, with some clashing aesthetics in the environment throughout the playthrough and giving off the sense of being set within a dream. Additionally, it includes rooms featuring personal hobbies as themes.
